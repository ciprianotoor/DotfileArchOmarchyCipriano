# CrimsonVoid — Omarchy theme

Tema de Omarchy de alto contraste en rojo, negro y blanco. Incluye estilos para
Hyprland, Waybar, Walker, Mako, SwayOSD, GTK, terminales, btop, Cava, Neovim,
VS Code y tres fondos SVG originales.

## Instalación

```bash
omarchy theme install https://github.com/ciprianotoor/DotfileArchOmarchyCipriano.git
omarchy theme set crimsonvoid
```

Para probar la copia local mientras se desarrolla:

```bash
ln -sfn "$PWD/.config/omarchy/themes/crimsonvoid" \
  "$HOME/.config/omarchy/themes/crimsonvoid"
omarchy theme set crimsonvoid
```

La estructura toma como referencia el ecosistema de temas de Omarchy y el
repositorio [Copper Night](https://github.com/hembramnishant50-glitch/omarchy-coppernight-theme),
pero los estilos y fondos de CrimsonVoid son propios.

## Paleta

Fondo `#08090D` · panel `#11131A` · rojo `#E53935` · rojo brillante `#FF5252` ·
blanco `#F5F7FA` · texto tenue `#A9B0BA`.
